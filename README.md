Customized-Screenshots-OCR —— 高精度视觉自动化引擎
不是 OCR，也不是 Clicker。
这是一个基于 AutoHotkey v2 的高精度视觉自动化引擎，专为非标准 UI、动态布局、复杂业务场景设计。
🔍 为什么它不同？
大多数自动化工具依赖：
控件 ID（无法用于游戏/网页）
图像匹配（慢且不鲁棒）
固定坐标（无法适应 DPI/分辨率）
而 Customized-Screenshots-OCR 通过：
✅ 颜色+几何逻辑双驱动 定位
✅ 行列分割算法 提取动态表格
✅ GDI+ 内存截图加速（性能提升 10x+）
✅ 多窗口独立运行 支持复杂流程
实现对任意视觉界面的精准操控。
