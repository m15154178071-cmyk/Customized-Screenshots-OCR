# Customized Screenshots OCR

Welcome to the Customized Screenshots OCR project!

## Overview
This project aims to provide an Optical Character Recognition (OCR) solution tailored for customized screenshots.

## Features
- Extract text from images of screenshots.
- Support for various image formats.
- Customizable functionality for specific screenshot goals.

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/m15154178071-cmyk/Customized-Screenshots-OCR.git
   ```
2. Navigate to the directory:
   ```
   cd Customized-Screenshots-OCR
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the application:
   ```
   python main.py
   ```
