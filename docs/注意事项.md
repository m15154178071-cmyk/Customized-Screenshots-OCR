# 注意事项（必读）

> 本文档总结了使用本项目（Customized-Screenshots-OCR）时必须注意的关键事项，强烈建议在实际部署和二次开发前仔细阅读。

---

## 1. 平台与依赖
- 仅支持 Windows 操作系统。
- 必须安装 AutoHotkey v2.0 及以上版本。
- 脚本所有功能均基于 AHK 原生命令实现，仅像素获取部分有底层优化。

## 2. 文件结构与运行方式
- 由于 AHK v2 不支持多文件类的跨文件调用，**建议所有代码均写在一个 .ahk 文件中**，统一编译和运行。
- 不建议拆分为多个 ahk 文件，否则类和全局变量可能无法互通。

## 3. 目标窗口识别
- `targetAppName` 支持窗口标题、`ahk_class`、`ahk_exe`、窗口ID等多种方式。
- 建议使用 WinSpy、AutoIt Window Info 等工具提前获取窗口唯一标识，避免识别错误。

## 4. 配置与调试
- 所有参数均集中在脚本头部的全局配置区，建议先备份再修改。
- 初次配置建议开启调试模式（`g_debugConfig["debugMode"] := true`），便于定位问题。
- 颜色、分割模数等参数无需精确，脚本会自动取最合适的值。

## 5. 兼容性与扩展性
- 本项目为工程化脚本，适合有一定 AHK 基础和空间想象力的用户。
- 仅适用于 Windows 桌面程序自动化，不适用于 Web、移动端等场景。
- OCR、截图等功能为扩展预留，当前主流程未直接调用。

## 6. 其他
- 建议使用管理员权限运行脚本，以避免权限不足导致的窗口操作失败。
- 如遇到脚本无响应、窗口找不到、颜色识别异常等问题，请优先查阅 docs/调试指南.md。
